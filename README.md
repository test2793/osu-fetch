## ✨ Features

* 🌸 **Aesthetic Visuals:** Beautiful osu! pink ASCII art logotype.
* ⚡ **Fast & Lightweight:** Powered by Python and the native osu! Legacy API v1.
* 📦 **Persistent Config:** Asks for your credentials only on the first run, then fetches instantly.

---

## 🚀 Installation

### Prerequisites

Make sure you have `python` and the `requests` library installed.

```bash
pip install requests
```

### Cloning the repository

```bash
git clone https://github.com/test2793/osu-fetch.git
cd osu-fetch
```

### Running the script

```bash
python osufetch.py
```
